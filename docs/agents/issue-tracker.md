# Issue source

Tickets live in [GitHub issue #1 and its children](https://github.com/Shu124/FolioAsk/issues/1).
Read a ticket with `gh issue view NUMBER --repo Shu124/FolioAsk --json title,body,state`.
Do not recreate local ticket copies. The product specification is `docs/mvp-spec.md`.

For each implementation, compare against the commit immediately before that ticket,
run independent Standards and Spec reviews, fix findings, then push the reviewed
commits. Leave release-verification tickets open until their external evidence exists.
